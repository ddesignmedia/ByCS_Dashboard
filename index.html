❓ Erklärung der Fachbegriffe einblenden

Interne Konsistenz (Cronbach-Alpha): Gibt an, wie zuverlässig der Test als Ganzes misst. Ein Wert von über 70% (0,70) ist gut und zeigt, dass alle Fragen harmonisch das gleiche Wissen/Konzept abfragen.

Standardfehler: Schätzt die statistische Ungenauigkeit der Noten. Ein kleiner Standardfehler (z. B. unter 10%) bedeutet, dass die Testnote das tatsächliche Wissen des Schülers sehr genau widerspiegelt.

Leichtigkeitsindex: Der prozentuale Durchschnitt der erreichten Punkte bei dieser Frage. Ein Wert von 86% bedeutet, dass die Frage einfach war (die Klasse hat 86% aller möglichen Punkte geholt). Werte unter 50% gelten als schwer.

Trennschärfeindex: Misst die Trennkraft einer Frage. Sie zeigt, ob leistungsstarke Schüler die Frage richtig lösen (Index ist positiv und hoch, idealerweise ≥ 30%) und schwächere Schüler sie eher falsch beantwortet haben. Liegt der Index nahe 0 oder ist negativ, ist die Frage ungeeignet oder verwirrend.

Trennschärfe-Effizienz: Vergleicht den tatsächlichen Trennschärfeindex mit dem theoretisch maximal möglichen Trennschärfewert für diese Frage. Je näher an 100%, desto effizienter differenziert die Frage.

📖 Kurzanleitung & Hilfe

So nutzen Sie das Mebis-Lernverlaufsdashboard Schritt für Schritt.

✨ Interaktive Präsentation starten

Sehen Sie sich die Möglichkeiten des Dashboards (automatisierte Defizitanalyse, Schüler-Tutor-Prompts, Highscores und Moodle-XML-Editor) in einer anschaulichen Schritt-für-Schritt-Präsentation an.

Präsentation öffnen

📥 1. Daten aus Mebis/ByCS-Lernplattform exportieren

Gehen Sie in Ihrer ByCS-Lernplattform (Mebis) zum gewünschten abgeschlossenen Test und laden Sie folgende drei Dateien herunter:

  • Ergebnis-Tabelle (JSON-Tabelle, erforderlich): Rufen Sie im Test „Ergebnisse“ → „Bewertungen“ auf. Wählen Sie im Dropdown für den Datenexport das Format JSON-Tabelle. Diese Datei enthält Noten, Punkte und Bearbeitungszeiten aller Schüler.
  • XML-Fragen-Export (Moodle-XML, erforderlich): Klicken Sie im Test auf das Zahnrad-Symbol → „Fragen-Export“ (oder nutzen Sie die Fragensammlung) und wählen Sie das Format Moodle-XML. Diese enthält Aufgabentexte, Antwortoptionen und Musterlösungen für die Fehlkonzept-Analyse.
  • Statistik-Bericht (JSON-Tabelle, optional aber empfohlen): Rufen Sie „Ergebnisse“ → „Statistik“ auf. Scrollen Sie ganz nach unten und exportieren Sie die Tabelle als JSON-Tabelle. Schaltet die detaillierte Fehlkonzept-Analyse und Trennschärfen auf der Klassenübersicht frei!

📤 2. Schülern die Daten bereitstellen

So richten Sie den anonymen Zugriff für Ihre Klasse ein:

  1. Erstellen Sie über das `+`-Symbol links eine Klasse, gehen Sie zu „Tests & Uploads“, benennen Sie den Test und laden Sie die 3 Mebis-Dateien hoch.
  2. Die Anwendung generiert automatisch anonyme, 5-stellige Codes für jeden Schüler. Drucken Sie diese über die Schaltfläche „Schüler-Codes drucken“ im Reiter Übersicht aus und teilen Sie sie den Schülern aus.
  3. Klicken Sie oben rechts auf das QR-Code-Symbol (Schüler-Portal). Dadurch wird Ihre einzigartige Raum-ID (z. B. TR-XXXXXX) an den Link angehängt. Zeigen Sie diesen QR-Code oder Link im Klassenzimmer.
  4. Die anonymisierten Testergebnisse werden automatisch auf den Server hochgeladen (z. B. als data_TR-XXXXXX.json). Schüler geben im Portal einfach ihren Code ein, um ihr persönliches Dashboard zu laden.

🤖 3. Mehrwert der KI-Auswertung (Klassen-Defizite)

Optimieren Sie Ihre Unterrichtsvorbereitung durch gezielte, KI-gestützte Fehleranalysen:

  • Top-5-Klassendefizite erkennen: Das Dashboard berechnet automatisch die Erfolgsquoten aller Fragen sowie statistische Trennschärfen, um die fünf schwierigsten Themenbereiche der Klasse hervorzuheben.
  • Vorgefertigter Prompt: Klicken Sie im Reiter Übersicht auf „🤖 KI-Prompt kopieren (Top 5 Defizite)“. Damit wird ein didaktisch optimierter Prompt inklusive Aufgabentexten und Fehlerstatistiken kopiert.
  • Didaktische Analyse & Tipps: Fügen Sie den Prompt in einen KI-Chatbot (wie ChatGPT, Claude, Gemini) ein. Sie erhalten sofort eine Analyse der typischen Fehlkonzepte Ihrer Schüler sowie konkrete Entwürfe, Erklärungen und Übungen für Ihre nächste Stunde.

💬 4. Lücken schließen mit dem Tutor-Prompt

Ermöglichen Sie Schülern das selbstgesteuerte und aktive Aufarbeiten ihrer Schwächen:

  • Individuelles Fehlerfeedback: Im Schüler-Portal sieht jeder Schüler exakt, bei welchen Aufgaben er Fehler gemacht hat (und wo der Rest der Klasse besser abgeschnitten hat).
  • Sokratischer Dialog statt fertiger Lösung: Der Schüler klickt im Portal auf „🤖 Alle Defizite als Tutor-Prompt kopieren“. Wenn er diesen Prompt in einen KI-Chatbot einfügt, schlüpft die KI in die Rolle eines sokratischen MINT-Tutors.
  • Aktives Lernen: Die KI verrät dem Schüler nicht die richtige Antwort, sondern stellt leitende Fragen. Der Schüler erarbeitet sich die Lösung so Schritt für Schritt selbst, was zu nachhaltigem Verständnis führt.

🛠️ 5. Moodle XML-Editor nutzen & anpassen

Prüfen und korrigieren Sie Moodle-Tests (z.B. von KIs generierte Fragen) vor dem Import in Mebis:

  • XML laden oder neu erstellen: Gehen Sie in den Reiter „Moodle XML-Editor“. Laden Sie eine Datei hoch, fügen Sie XML-Code per Copy-Paste ein oder starten Sie einen neuen Test von Grund auf.
  • Visuelles Editieren: Jede Frage wird als ausklappbare Karte dargestellt. Sie können Fragen-Titel, Aufgabentexte (inkl. HTML/LaTeX) und die Antwortoptionen bzw. Zuordnungspaare direkt bearbeiten.
  • Reihenfolge & Fragentyp ändern: Verschieben Sie Fragen mit den Tasten 🔼/🔽, löschen Sie Fragen oder fügen Sie neue hinzu. Sie können auch den Fragentyp (z. B. von Kurzantwort zu Multiple Choice) jederzeit per Dropdown wechseln.
  • Valider XML-Export: Klicken Sie auf „XML exportieren und herunterladen“. Das Tool validiert die Struktur und lädt eine bereinigte, Moodle-kompatible Datei herunter, die sich fehlerfrei in Mebis importieren lässt.

🔒 Datenschutz-Hinweis (100% DSGVO-konform): Alle originalen Mebis-Dateien mit Klarnamen werden ausschließlich lokal in Ihrem Webbrowser verarbeitet und niemals an einen Server übertragen. Nur die vollständig anonymisierten Testergebnisse ohne Schülernamen werden unter der zufälligen Raum-ID auf den Server hochgeladen, damit Schüler darauf zugreifen können.
